
# WTCmart

### Smart Shopping & Retail Management

WTCmart is a modern retail shopping web application designed to provide users with a simple and convenient way to explore products, manage their shopping experience, and interact with a digital marketplace.

## Features

- Browse available products
- Explore products through a clean interface
- View product information
- Search and discover products
- Add products to the shopping cart
- Manage selected items before checkout
- Responsive design for different screen sizes
- User-friendly shopping experience

## How to Use

1. Open WTCmart in your browser.
2. Browse the available products.
3. Explore product details and pricing.
4. Add your desired products to the shopping cart.
5. Review your selected items.
6. Continue with the available shopping or checkout options.

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS

## Installation

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/ohi07/WTCmart.git
```

### Navigate to the Project

```bash
cd WTCmart
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm run dev
```

Open the local development URL in your browser.
